# Return coherent terminal state from matched SLDS controls

## Background in Plain English — WHY

The matched SLDS control fitter installs a new parameter state and then returns
inference from the preceding state. Downstream scoring can therefore combine
beliefs and parameters from different outer iterations. That result is not a
coherent fitted model, even when the outer residual itself is reported
correctly.

The controls must return one internally consistent terminal state before they
can diagnose the rSLDS outer learner.

## Outcomes / Acceptance Criteria — WHAT

1. The fitter performs terminal inference after its final accepted parameter
   installation.
2. Returned inference, beliefs, posteriors, and point parameters describe the
   same outer state.
3. Phase and work records expose the terminal solve with the same status
   vocabulary used by the rSLDS fitter.
4. A failed or non-finite terminal solve cannot be reported as converged.
5. Focused compact, budget-exhausted, diverged, and non-finite tests pass.
6. Completed `cff-oyie` artifacts remain immutable, and the work runs no
   registered final seed.

## Methodological Suggestions — HOW

These suggestions are optional. The implementer may choose another sound
method that satisfies the outcomes.

- Mirror the rSLDS terminal inference and phase-record contract in the sibling
  experiment.
- Preserve the existing outer iteration and residual behavior in this ticket.
- Keep the returned state, posterior, point parameters, and metrics in one
  explicit terminal record.

## Future work

`cff-0xjq` uses the coherent control result in a bounded development replay.
`cff-qulu` owns any later shared outer controller. This ticket does not add
globalization.

## Definitions

- **Matched SLDS control:** The ordinary switching linear dynamical system used
  as a recurrence-free comparison for the rSLDS learner.
- **Terminal inference:** One inference solve after the last parameter write,
  used to make returned beliefs and parameters describe the same model.

## Notes

Architecture handoff: this is the sibling experiment's matched-control fitting
boundary. CFFG IR, compiler, VM, schedule, kernels, ledger, serialization,
learnables, and engine status semantics are N/A.

Duplicated surfaces: same-K and K=5 controls, converged and exhausted exits,
phase work, returned beliefs, prediction parameters, and downstream scoring
must stay aligned. Every improper or non-finite terminal result fails loudly.
