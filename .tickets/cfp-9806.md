# Wire the checked two-pass reactor reference into a reproducible closed-loop pilot

## Background in Plain English — WHY

The nine retained plans check equations at fixed windows. They do not answer whether the controller tracks a changing reactor setpoint. This pilot connects the existing float64 reference to actual successive simulated observations. Start both workstreams from the shared handoff above PR #185 (cff-adaptive-runtime at f9df9d6), including the directed reference in 265ff14. Each workstream can branch independently.

## Outcomes / Acceptance Criteria — WHAT

1. A versioned command in the PCGym experiment checkout runs one complete seeded episode with four past steps, fifteen future steps, the retained RK4 plant, known constants and the original observation/goal/noise conventions.
2. Every tick records its input window, masks, setpoint preview, proposed and applied coolant, status, fallback and timing. Preserve the first failing window if the trajectory leaves the validated envelope; count it in the episode outcome.
3. On retained real windows including a changed goal/history, replay the stock solver against the same input and compare both directions, returned action, residual and objective at the cold-start study tolerances. Record any divergence before interpreting control performance.
4. The handoff fixes seeds, a comparison controller, knowledge/preview access, actuator clipping, deadline or budget, and outcomes for the paired study before looking at comparative returns.

## Methodological Suggestions — HOW

Use ~/experiments/cffg-testing/pc-gym/00/cffg/validation/v2_cstr_nonlinear_chain.py and v2_cstr_hostlin_baseline.py. The fast calculation and --stock-rules live in tools/benchmark_cstr_chain.py. See ~/agent-share/cffg-cold-start/check_all.py. Architecture row: Runtime numerical or status invariant, consumer validation only. Compare directed/stock on the same bound data; Colony, training, checkpoint changes and new engine rules are N/A.

Pin the imported library path and revision separately from the reference: stock PR #185 is f9df9d6, reference source is 265ff14, and the external experiment’s nested checkout was still at ead32f1 during this audit. Align both controllers on observation-to-applied-action timing, including readout and clipping. Historical scripts used different timer boundaries.

## Future work

The paired control study consumes the pilot. Uncertain parameters, bounded optimization and automatic Engine dispatch have separate owners.

## Definitions

RK4 is the four-stage numerical integrator used for reactor physics. A setpoint is the plant output the controller should track. Preview is access to future setpoints.
