Can two moves tell you where you are?

Two junctions and their exits look alike. A navigator that remembers what it saw and how far it actually moved may recognise which junction it reached. This study tests that idea on a familiar map and on two changed maps.

    What each model knows

    One move can remove one kind of uncertainty

    Every model receives the current symbol, the applied compass command and the measured change in position. An east command with displacement (0, 0) tells the navigator it stayed put. Adding the measured displacements to a known start gives its position. The same symbol can still refer to more than one place in the learned model.

    Three uses of the same experience

    The immediate model pools all visits bearing the same symbol. The history model can also use the last two completed commands, their displacements and the three symbols they connect. It retains a sequence seen at least twice during fitting if the final symbol occurred at several positions. Missing sequences fall back to the current symbol. The tile model keeps the positions and directed links it experienced. All three learn from the same exploration, then stay frozen as the map changes.

    Reading one and three moves ahead

    The fitted tables count which symbol followed each prescribed command string. A missing history forecast uses the appearance row if available. With no matching row, the model assigns equal probability to each symbol. The tile model follows its fitted links and also returns equal probabilities for an unknown link. A 1% uniform mixture keeps every endpoint possible. On this categorical tree, the native Bethe free energy equals the negative natural logarithm of the probability assigned to the observed endpoint.
